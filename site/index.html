A niri desktop for Fedora, ready in one command.

Firelink sets up niri and everything a desktop needs around it: a bar, a launcher, notifications, a lock screen, clipboard history and more, all in one Catppuccin theme.

Fedora 44
$ curl -fsSL https://firelink.estuslabs.com/install | bash

Then log out and pick Niri on the login screen. Read the script first if you like; it's short. New machine? Start from scratch.

01 What it installs

Only what the desktop needs. Packages come from Fedora's own repositories, and sudo is only used to install them (and to set up a login screen on machines without one). It works on Workstation, a spin or a bare Server install; GNOME isn't needed. Beyond Firefox, no browsers, chat apps or anything else you didn't ask for.

  • niriThe compositor. Scrolling tiling, an overview, gestures.
  • WaybarWorkspaces, clock, audio, network, Bluetooth, battery.
  • fuzzelThe app launcher and one menu for everything else: capture, toggles, theme, Wi-Fi, Bluetooth, default browser, power.
  • mako, wobNotifications with do not disturb, and a slim bar for volume and brightness.
  • swaylock, swayidleLocks after five minutes; suspends on battery.
  • SattyScreenshots you can annotate, plus screen recording.
  • Alacritty, NeovimThe terminal and the editor.
  • NautilusThe file manager, on SuperE.
  • FirefoxA browser to start with, on SuperB. Use it to get another.
  • cliphist, wlsunsetClipboard history and a night light.

Satty and the wallpapers are downloaded at fixed versions and checked against known hashes. If GNOME is installed too, it's left alone: Firelink's services only run in a niri session.

02 Starting from scratch

Firelink installs on any Fedora 44. On a new machine or a VM, there are two good places to start:

  • WorkstationFedora's GNOME desktop. Firelink adds niri alongside it and uses GNOME's login screen, where you pick either one. Easiest if you'd like GNOME around too.
  • Everything netinstallA bare system with no desktop. Firelink brings the rest, including a login screen, so you get niri and nothing else. Smaller, and up to date from the start.

From Workstation, install it as usual and run the command above. From the Everything netinstall:

  1. Download the Everything netinstall ISO (under 1 GB) and write it to a USB stick with Fedora Media Writer, or boot it in a VM.
  2. In the installer, under Software Selection, choose Minimal Install. Packages download during the install, so connect to a network.
  3. Under User Creation, make your user and tick Make this user administrator so it can use sudo.
  4. Reboot, log in at the text console, and run the install command.
  5. Reboot again. Firelink's login screen comes up; log in and niri starts.

In a VM, turn on 3D acceleration: niri needs working graphics.

05 Making it yours

Firelink keeps its defaults in ~/.local/share/firelink. Your files in ~/.config include them, and anything you add after that wins. firelink update brings in new defaults and never touches your files; an icon in the bar tells you when there's one.

Displays

Monitors are set in ~/.config/niri/config.kdl, after Firelink's include. niri msg outputs lists their names and modes, and niri applies the file as soon as you save it.

// ~/.config/niri/config.kdl
include "~/.local/share/firelink/config/niri/firelink.kdl"

// Yours from here down. The laptop's panel:
output "eDP-1" {
    mode "1920x1200"
    scale 1.25
    position x=0 y=0
}

// A monitor named by make, model and serial follows you to any port
output "Dell Inc. DELL U2723QE ABC1234" {
    scale 1.5
    position x=1536 y=0
}

Positions are in scaled pixels: the panel is 1920 wide at scale 1.25, so 1536, and the monitor starts there. Other options include transform "90" to rotate a screen and off. To try a setting before saving it, run niri msg output eDP-1 scale 1.5; it lasts until the config is loaded again.

Wallpaper

Each flavor comes with its own wallpaper. To use yours instead, copy it to ~/.config/firelink/wallpaper. It stays when you switch flavors or update.

mkdir -p ~/.config/firelink
cp ~/Pictures/mine.jpg ~/.config/firelink/wallpaper
systemctl --user restart firelink-swaybg

Delete that file and run the last line again to go back to the flavor's wallpaper.

Browser

Firefox comes with Firelink and opens on SuperB. To use another browser, install it from its own site (Chrome and Brave have Fedora instructions) or from Flathub, then pick it under Browser in the Firelink menu, on SuperSpace. Links and SuperB open it from then on. Saying yes when a browser asks to be the default does the same thing. From a terminal:

xdg-settings get default-web-browser
xdg-settings set default-web-browser brave-browser.desktop
